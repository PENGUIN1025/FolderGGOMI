# 접다: 결정 사항 기록

요구사항 문서(v1)에 없거나 모호해서 개발 중에 정한 내용이다. 문서를 고칠 때 이 내용을 반영한다.

## 기본 설정

| 항목 | 결정 |
|---|---|
| 패키지명 | `com.aggro1025.jeopda` |
| 최소 안드로이드 버전 | minSdk 26 (Android 8.0), targetSdk 36 (Google Play 요구사항) |
| 배포 | Play Console 내부 테스트 (docs/play-console.md) |
| 개인정보처리방침 | https://penguin1025.github.io/jeopda-privacy/ (공개 저장소 jeopda-privacy에 docs/privacy/index.html을 올려 GitHub Pages로 게시). 내용이 바뀌면 그 저장소의 index.html을 교체 |
| UI 기술 | Kotlin + Jetpack Compose |
| 개발·테스트 | 맥 Android Studio, 실제 기기 S23 Ultra |

## v0.1 동작

| 항목 | 결정 |
|---|---|
| 메뉴 1~5번 | **1 전화, 3 연락처는 폴더폰 화면 안에서** 동작 (다이얼러, 연락처 목록). 2 문자, 4 알람, 5 카메라는 기기 기본 앱. 통화 중 화면은 삼성 화면 그대로 |
| 전화 걸기 | 다이얼러·연락처에서 통화 키를 누르면 바로 걸기 (전화 걸기 권한). 권한을 거절하면 기본 전화 앱에 번호를 채워서 연다 |
| 연락처 | 이름순 목록, ▲▼로 선택, 통화 키로 걸기, 소프트키 "문자"로 기본 문자 앱 작성 화면. 숫자키로 초성 찾기(천지인 자음: 4 → ㄱㅋ). 숫자 3개 이상이면 번호로도 찾기 |
| 문자 | 읽기·보내기를 직접 하지 않음 (기본 문자 앱 지정이 필요하고 구글 플레이가 엄격히 제한). 기본 문자 앱으로 넘김 |
| 메뉴 6~9번 | 사용자 선택 앱. v0.1은 카테고리·차단 목록 필터 없음 (v0.2에서 적용) |
| 화면 구성 | 위 약 55% 디스플레이, 아래 약 45% 폴더폰 버튼부. 사유 입력 중 키보드가 뜨면 버튼부를 숨김 |
| 홈에서 숫자키 | 그 숫자가 입력된 폴더폰 다이얼러를 연다 |
| 긴급번호 | 112·119 등은 기본 전화 앱에 번호가 입력된 상태로 열리고, 사용자가 통화 버튼을 한 번 더 누른다 (안드로이드 제약) |
| 스마트폰 모드 홈 | **원래 홈 앱(One UI 홈 등)으로 중계**. 접다는 계속 기본 홈 앱으로 남아, 시간이 끝나면 홈 버튼에서 폴더폰 화면이 나온다. 원래 홈 앱이 없거나 실패하면 접다의 단순 앱 목록을 보여준다 |
| 남은 시간 표시 | 알림창의 상시 알림 (남은 시간, "폴더폰으로 돌아가기") |
| 해제 시간 입력 | 5분 단위, 최소 5분, 최대 12시간 |
| 사유 글자 수 | 공백을 빼고 10글자 이상. 같은 글자만 반복하면 거절 |
| 사유 빠른 선택지 | 제공 (업무 연락 확인, 길찾기, 결제·송금, 사진 정리). 눌러도 10글자 규칙은 그대로 |
| 무료 1회 소진 후 | 광고·결제는 "준비 중"으로 비활성화. 디버그 빌드에만 "개발용 해제" 표시 |
| 종료 5분 전 알림 | "알람 및 리마인더" 권한을 안내. 꺼져 있으면 부정확한 알람으로 대체 (모드 복귀 자체는 정확) |
| 시계 조작 방지 | v0.2로 미룸 |
| 설치된 앱 목록 조회 | `QUERY_ALL_PACKAGES` 사용 (런처 용도) |
| 폴더폰 모드 상태 표시줄 | 시스템 상태 표시줄을 숨기고 화면 안 자체 상태 표시줄 사용 |

## 디자인

- 기본 디자인: 2000년대 컬러 폴더폰 스타일 화면(남색 배경화면, 화면 안 상태 표시줄, 아이콘 격자 메뉴) + 검은 통판 키패드(백라이트 글자, 수화기 아이콘, 고리 방향키, 천지인 보조 글자)
- 참고: 노키아 6600 폴드, 3120 클래식 실제 화면 (GSMArena 리뷰)

## v0.2 결정 (2026-11-27)

| 항목 | 결정 |
|---|---|
| 진행 순서 | v0.2a(돈 무관: 알림 차단, 메뉴 제한, 권한 안내·설정 새 디자인, 시계 조작 방지, 홈 앱 해제 감지, 앱 크기 축소) → v0.2b(광고·결제) |
| 메뉴 앱 제한 | 문서대로 소셜·영상·게임 카테고리, 차단 목록, 브라우저, 플레이스토어 금지 (메신저 예외). 음악 앱은 허용 |
| 차단 목록 초기값 | 인스타그램, 유튜브, 틱톡, 페이스북, X, 넷플릭스, 스레드, 스냅챗, 트위치. 앱 안 파일로 시작 |
| 알림 허용 앱 3개 | 메뉴 앱처럼 스마트폰 모드와 최초 설정에서만 편집 |
| 광고 로드 실패 대기 | **1분** (문서의 1분 30초에서 변경) |
| v0.2a 임시 해제 | 광고·결제가 나오기 전까지 "1분 기다리고 해제"를 광고 자리에 제공 |
| 500원 결제 | 문서대로 (해제 방법 중 하나, 소모성, 광고 횟수 제한 없음) |
| 시계 조작 방지 | 폰의 네트워크 시간(Android 13+ `SystemClock.currentNetworkTimeClock`) 기준. 못 받으면 폰 시계를 쓰되 부팅 후 경과 시간으로 앞당김 흔적이 있으면 막음 |
| 소프트키 이름 | 디스플레이 아래가 아니라 버튼부 파란 막대 위(좌·우)와 확인 키 안(가운데)에 표시 |
| 설정 화면 | 폴더폰과 같은 남색 스타일, 맨 위에 "정보를 가져가지 않아요" 안내, 단계별 체크리스트 |
