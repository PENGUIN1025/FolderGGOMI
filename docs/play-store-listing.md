# Play Console 앱 설정 답변

## v0.4.0 (500원 결제 추가)

- 인앱 상품: 수익 창출 → 인앱 상품 → 상품 ID `refill_free_unlocks`, 이름 "무료 해제 초기화", 설명 "오늘 무료 해제를 3회로 초기화해요", 가격 ₩500, **활성**
- 콘텐츠 등급 설문: **디지털 상품 구매 → 예** 로 다시 제출
- 로그인 세부정보(앱 액세스): 그대로 "아니요" (무료·광고로 모든 기능 사용 가능, 결제는 무료 횟수 충전일 뿐)
- 데이터 보안: 결제는 Google Play가 처리, 접다는 결제 토큰만 기기에 저장 → 추가 "수집" 없음
- 결제 시험: 설정 → 라이선스 테스트에 본인 Gmail 등록 후, 플레이스토어에서 받은 접다로 테스트 카드 결제

## v0.4.0 (다른 앱 막기)

- 새 권한: 사용 기록 접근(PACKAGE_USAGE_STATS), 다른 앱 위에 표시(SYSTEM_ALERT_WINDOW). 별도 신고서는 없지만, 앱 안 설명(설정 단계)과 개인정보처리방침에 목적을 적어 둠
- 데이터 보안: 사용 기록은 기기 안에서만 확인하고 저장·전송하지 않으므로 "수집" 아님 (광고 SDK 항목은 v0.3.0 그대로)

### 데이터 보안: 광고 SDK가 수집하는 항목

구글 공식 안내 "Google Mobile Ads SDK 데이터 공개"를 기준으로 작성. 입력 전에 그 문서의 최신 내용과 한 번 대조할 것.

| 데이터 유형 | 수집 | 공유 | 용도 | 선택 여부 |
|---|---|---|---|---|
| 위치 > 대략적인 위치 (IP 기반) | 예 | 예 | 광고, 분석, 사기 방지 | 필수 아님(광고를 볼 때만) |
| 앱 활동 > 앱 상호작용 (광고 노출·클릭) | 예 | 예 | 광고, 분석 | 필수 아님 |
| 앱 정보 및 성능 > 비정상 종료 로그, 진단 | 예 | 예 | 분석, 사기 방지 | 필수 아님 |
| 기기 또는 기타 ID > 광고 ID 등 | 예 | 예 | 광고, 분석, 사기 방지 | 필수 아님 |

연락처, 알림 내용, 해제 사유, 설치된 앱 목록은 여전히 **수집하지 않음** (기기 안에서만 사용).

참고: 광고 SDK가 `FOREGROUND_SERVICE`, `AD_ID`, `INTERNET` 권한을 함께 추가한다. 포그라운드 서비스 유형 권한은 없어서 별도 신고는 필요 없을 것으로 보이지만, Play Console이 요구하면 "광고 SDK 내부 작업"으로 답한다.

v0.2a(0.2.0)에서 바뀐 것: 자세한 설명에 알림 차단·1분 대기 추가, 알림 접근 권한 안내 추가. 나머지 신고(광고 없음, 데이터 수집 없음, 콘텐츠 등급)는 그대로.

광고·결제를 붙이는 v0.2에서 **광고, 콘텐츠 등급, 데이터 보안**을 다시 작성해야 한다.

## 1. 스토어 등록정보 (기본 스토어 등록정보)

- **앱 이름**: 접다 - 폴더폰 모드
- **간단한 설명** (80자 이내):

```
스마트폰을 폴더폰처럼. 홈 화면은 단순하게, 스마트폰은 꼭 필요할 때만.
```

- **자세한 설명** (4000자 이내):

```
폰을 덜 보고 싶은데, 앱을 지우기는 어렵다면.
접다는 홈 화면을 폴더폰처럼 바꿔 주는 홈(런처) 앱입니다.

■ 폴더폰 홈 화면
- 시계, 날짜, 배터리만 보이는 단순한 대기 화면
- 화면 아래 폴더폰 키패드로 조작 (소프트키, 방향키, 통화·종료 키, 숫자키)

■ 숫자키 메뉴 1~9
- 전화, 문자, 연락처, 알람, 카메라 + 직접 고른 앱 4개
- 숫자를 누르면 바로 열려요

■ 폴더폰 화면 안의 전화와 연락처
- 홈에서 숫자를 누르면 바로 다이얼러
- 연락처는 숫자키로 초성 찾기 (4 → ㄱㅋ)

■ 필요한 알림만
- 폴더폰 모드에서는 전화, 문자, 알람, 재난문자와 직접 고른 앱 3개의 알림만 남겨요
- 나머지 앱 알림은 바로 지워요 (음악 재생처럼 계속 떠 있는 알림은 그대로예요)

■ 다른 길로 새지 않게
- 폴더폰 모드에서 최근 앱 화면 등으로 메뉴에 없는 앱을 열면 폴더폰 화면으로 돌아와요

■ 스마트폰으로 돌아갈 때는 이유를 적어요
- 하루 3회 무료, 또는 광고를 보고 폴더폰 모드를 해제할 수 있어요
- 무료를 다 썼다면 500원으로 오늘 무료 해제를 초기화할 수 있어요
- 쓸 시간(최대 12시간)과 이유(6글자 이상)를 직접 적어요
- 스마트폰 모드에서는 원래 쓰던 홈 화면이 그대로 떠요
- 끝나기 30분 전·10분 전에 알려 주고, 시간이 끝나면 폴더폰 화면으로 돌아와요
- 언제든 일찍 돌아갈 수도 있어요

■ 알아 두세요
- 접다는 홈 화면을 바꾸는 앱입니다. 휴대전화 설정에서 기본 홈 앱을 바꾸거나 앱을 삭제하면 언제든 원래대로 돌아갈 수 있어요.
- 전화와 긴급번호(112, 119)는 언제나 쓸 수 있어요. 긴급번호는 기본 전화 앱에서 통화 버튼을 한 번 더 누르면 걸려요.

■ 권한 안내
- 설치된 앱 목록: 메뉴에 넣을 앱을 고르고, 스마트폰 모드에서 원래 홈 화면을 찾기 위해
- 알림 접근: 허용하지 않은 앱의 알림을 지우기 위해 (알림 내용은 읽거나 저장하지 않아요)
- 사용 기록 접근, 다른 앱 위에 표시: 폴더폰 모드에서 메뉴에 없는 앱이 열리면 폴더폰 화면으로 돌려보내기 위해 (지금 맨 앞 앱만 확인, 기록은 저장하지 않아요)
- 연락처: 폴더폰 화면에 연락처를 보여주기 위해 (기기 밖으로 보내지 않아요)
- 전화 걸기: 번호를 누르면 바로 전화를 걸기 위해
- 알림, 알람 및 리마인더: 스마트폰 모드 남은 시간과 종료 5분 전 알림
```
