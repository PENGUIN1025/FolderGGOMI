# Play Console 앱 설정 답변 (v0.2a 기준)

v0.2a(0.2.0)에서 바뀐 것: 자세한 설명에 알림 차단·1분 대기 추가, 알림 접근 권한 안내 추가. 나머지 신고(광고 없음, 데이터 수집 없음, 콘텐츠 등급)는 그대로.

광고·결제를 붙이는 v0.2에서 **광고, 콘텐츠 등급, 데이터 보안**을 다시 작성해야 한다.

## 1. 스토어 등록정보 (기본 스토어 등록정보)

- **앱 이름**: 접다 - 폴더폰 모드
- **간단한 설명** (80자 이내):

```
스마트폰을 폴더폰처럼. 홈 화면은 단순하게, 스마트폰은 꼭 필요할 때만.
```

- **자세한 설명** (4000자 이내):

```
폰을 덜 보고 싶은데, 앱을 지우기는 어렵다면.
접다는 홈 화면을 폴더폰처럼 바꿔 주는 홈(런처) 앱입니다.

■ 폴더폰 홈 화면
- 시계, 날짜, 배터리만 보이는 단순한 대기 화면
- 화면 아래 폴더폰 키패드로 조작 (소프트키, 방향키, 통화·종료 키, 숫자키)

■ 숫자키 메뉴 1~9
- 전화, 문자, 연락처, 알람, 카메라 + 직접 고른 앱 4개
- 숫자를 누르면 바로 열려요

■ 폴더폰 화면 안의 전화와 연락처
- 홈에서 숫자를 누르면 바로 다이얼러
- 연락처는 숫자키로 초성 찾기 (4 → ㄱㅋ)

■ 필요한 알림만
- 폴더폰 모드에서는 전화, 문자, 알람, 재난문자와 직접 고른 앱 3개의 알림만 남겨요
- 나머지 앱 알림은 바로 지워요 (음악 재생처럼 계속 떠 있는 알림은 그대로예요)

■ 스마트폰으로 돌아갈 때는 이유를 적어요
- 하루 1회 무료, 또는 1분 기다리면 스마트폰 모드를 켤 수 있어요
- 쓸 시간(최대 12시간)과 이유(10글자 이상)를 직접 적어요
- 스마트폰 모드에서는 원래 쓰던 홈 화면이 그대로 떠요
- 끝나기 5분 전에 알려 주고, 시간이 끝나면 폴더폰 화면으로 돌아와요
- 언제든 일찍 돌아갈 수도 있어요

■ 알아 두세요
- 접다는 홈 화면을 바꾸는 앱입니다. 휴대전화 설정에서 기본 홈 앱을 바꾸거나 앱을 삭제하면 언제든 원래대로 돌아갈 수 있어요.
- 알림창, 최근 앱 화면 등 홈 화면이 아닌 경로로 다른 앱을 여는 것까지 막지는 않아요.
- 전화와 긴급번호(112, 119)는 언제나 쓸 수 있어요. 긴급번호는 기본 전화 앱에서 통화 버튼을 한 번 더 누르면 걸려요.

■ 권한 안내
- 설치된 앱 목록: 메뉴에 넣을 앱을 고르고, 스마트폰 모드에서 원래 홈 화면을 찾기 위해
- 알림 접근: 허용하지 않은 앱의 알림을 지우기 위해 (알림 내용은 읽거나 저장하지 않아요)
- 연락처: 폴더폰 화면에 연락처를 보여주기 위해 (기기 밖으로 보내지 않아요)
- 전화 걸기: 번호를 누르면 바로 전화를 걸기 위해
- 알림, 알람 및 리마인더: 스마트폰 모드 남은 시간과 종료 5분 전 알림
```

### 콘텐츠 등급 설문

- 카테고리: **기타 모든 앱 유형** (유틸리티, 생산성 등)
- 폭력, 성적 콘텐츠, 비속어, 약물, 도박: 모두 **아니요**
- 사용자 간 소통·콘텐츠 공유: **아니요**
- 사용자 위치 공유: **아니요**
- 디지털 상품 구매: **아니요** (v0.2에서 500원 결제 추가 시 **예**로 변경)
- 예상 결과: 전체이용가

### 데이터 보안

- 필수 사용자 데이터를 수집하거나 공유하나요? **아니요**
  - 연락처는 기기 안에서 화면에 보여주는 데만 쓰고 저장·전송하지 않음 (Play 기준 "수집" 아님)
  - 해제 사유, 메뉴 설정은 기기 안에만 저장
  - 앱에 인터넷 권한이 없음
